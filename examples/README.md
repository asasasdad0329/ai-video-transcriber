| 檔案 | 內容 |
| --- | --- |
| [transcript.md](coscup-2012-final-fantasy/transcript.md) | 逐字稿主稿：口述全文，投影片與終端機畫面以「畫面補充」插在對應位置 |

# Example: a COSCUP 2012 lightning talk

Real output from running this project on a Creative Commons video: a 5-minute-6-second talk given over slides and terminal sessions.

| File | Content |
| --- | --- |
| [transcript.md](coscup-2012-final-fantasy/transcript.md) | Primary transcript: the full spoken text, with slide and terminal text placed where it appears ("畫面補充") |
| [datacard.md](coscup-2012-final-fantasy/datacard.md) | Data card: Markdown for AI readers, keeping the transcript's wording, with sections, keywords and a list of words still to verify |
| [handout-pages.png](coscup-2012-final-fantasy/handout-pages.png) | Preview of pages 1 and 6 of the handout (DOCX) |
